여기서 좋은 점

API 주소가 필요 없다

  • route.ts 파일 없음
  • /api/login 주소 설계 없음
  • fetch 호출 없음

서버 코드가 브라우저에 없다

  • DB 접속 정보 안 내려감
  • API 키 안 내려감
  • 함수 본문이 브라우저 코드에 없음

폼 코드가 짧아진다

  • useState 없음
  • onSubmit · preventDefault 없음
  • fetch · JSON.stringify 없음

오늘의 정리

"use server"

이 함수는 서버에서만 실행하라는 표시

action={login}

form에 함수를 그대로 연결 — 주소를 만들지 않는다

formData.get("email")

input의 name으로 값을 꺼낸다

클라이언트 컴포넌트에서
Server Actions 쓰기

화면에 상태나 이벤트가 필요해지면 페이지에 "use client"가 붙습니다

"use client" 안에서는 안 된다

page.tsx

한 파일에 같이 두기

  • "use client" 파일 안에서 함수 정의
  • 함수 첫 줄에 "use server"
  • Next.js가 에러로 막는다
// page.tsx "use client"; const login = async () => { "use server"; };

파일 2개

함수를 따로 빼기

  • src/actions/login.ts 새로 만들기
  • 파일 최상단에 "use server"
  • 화면에서는 import 해서 사용
// actions/login.ts "use server"; export const login = ...
// page.tsx "use client"; import { login } from "@/actions/login";

파일을 나누는 이유

"use client" 파일은 브라우저로 통째로 내려간다

그 안에 서버 함수를 두면 DB 접속 정보와 API 키도 같이 내려간다

It is not allowed to define inline "use server" annotated Server Actions in Client Components.

완성 코드

src/actions/login.ts

"use server";

export type LoginState = {
  message: string;
  success: boolean;
};

export async function login(
  prevState: LoginState,
  formData: FormData
): Promise<LoginState> {
  const email = formData.get("email") as string;
  const password = formData.get("password") as string;

  await new Promise((resolve) => setTimeout(resolve, 1000));

  if (password.length < 8) {
    return { message: "비밀번호는 8자 이상이어야 합니다.", success: false };
  }

  return { message: `${email}님 환영합니다.`, success: true };
}

src/app/login/page.tsx

"use client";

import { useActionState } from "react";
import { login, type LoginState } from "@/actions/login";

const initialState: LoginState = { message: "", success: false };

export default function LoginPage() {
  const [state, formAction, isPending] = useActionState(login, initialState);

  return (
    <form action={formAction}>
      <input type="email" name="email" required />
      <input type="password" name="password" required />
      <button type="submit" disabled={isPending}>
        {isPending ? "로그인 중..." : "Login"}
      </button>

      {state.message && (
        <p style={{ color: state.success ? "green" : "red" }}>{state.message}</p>
      )}
    </form>
  );
}
