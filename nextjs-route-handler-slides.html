규칙 ① 파일 이름과 위치

app 폴더 안에, 이름은 정확히 route.ts

app/
 └ api/
    └ hello/
       └ route.ts   ← 이 파일이 API가 됩니다

Next.js는 app 폴더 안의 route.ts라는 이름만 API로 인식합니다.

STEP 1

함수를 내보내기

// src/app/api/posts/route.ts

export function

route.ts 안의 함수는 우리가 직접 부르지 않습니다 — Next.js가 가져다 실행할 수 있게 export로 내보냅니다.

STEP 2

이름은 대문자 GET

// src/app/api/posts/route.ts

export function GET() {

}

이름이 곧 요청의 종류. 반드시 대문자 GET — get, Get은 동작하지 않아요.

STEP 3

답장할 데이터 준비

// src/app/api/posts/route.ts

export function GET() {
  const posts = [
    { id: 1, title: "첫 글", contents: "안녕하세요!" },
    { id: 2, title: "둘째 글", contents: "반갑습니다!" },
  ];
}

답장으로 보낼 게시물 2개를 배열 [ ] 로 준비 — id · title · contents

STEP 4

JSON으로 답장하기

// src/app/api/posts/route.ts

export function GET() {
  const posts = [
    { id: 1, title: "첫 글", contents: "안녕하세요!" },
    { id: 2, title: "둘째 글", contents: "반갑습니다!" },
  ];
  return Response.json(posts);
}

return이 곧 답장. Response.json(posts) — posts 배열이 그대로 JSON으로 나갑니다.

완성 코드

// src/app/api/posts/route.ts

export function GET() {
  const posts = [
    { id: 1, title: "첫 글", contents: "안녕하세요!" },
    { id: 2, title: "둘째 글", contents: "반갑습니다!" },
  ];
  return Response.json(posts);

복사 버튼을 눌러 route.ts에 붙여넣으세요

화면에서 불러오기 — page.tsx

// src/app/page.tsx

"use client";

import { useEffect, useState } from "react";
type Post = { id: number; title: string; contents: string };

export default function Home() {
  const [posts, setPosts] = useState<Post[]>([]);

  useEffect(() => {
    fetch("/api/posts")
      .then((res) => res.json())
      .then((data) => setPosts(data));
  }, []);

  return (
    <ul>
      {posts.map((post) => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  );
}

읽기만 할 땐 fetch("/api/posts") 한 줄 — 화면이 처음 뜰 때 한 번 불러와(useEffect) 목록으로 그립니다

오늘의 정리

route.ts

app 폴더 안에 만들면 API가 되는 특별한 파일

폴더 위치 = API 주소

app/api/posts → /api/posts — 화면(page.tsx)과 주소가 겹치면 안 됨

GET

대문자로 내보내면 "데이터 주세요" 요청을 처리

데이터 보내기 — POST

받기(GET) 다음은 보내기 — 그리고 화면과 연결하기

요청의 두 방향

받기는 GET, 보내기는 POST

GET — 주세요

데이터 받기 · 주소창에 치는 게 GET

POST — 받아주세요

데이터 보내기 · 주소창으론 못 보냄

POST 연습하기

STEP 1

배열을 함수 밖으로

DB가 없어서 임시로 배열에 저장하는 방식이에요

// src/app/api/posts/route.ts

const posts = [
  { id: 1, title: "첫 글", contents: "안녕하세요!" },
  { id: 2, title: "둘째 글", contents: "반갑습니다!" },
];

export function GET() {
  return Response.json(posts);
}

STEP 2

POST 함수 만들기

// src/app/api/posts/route.ts

const posts = [ ... ];

export function GET() { ... }

export async function POST(request: Request) {

}

이름은 반드시 대문자 POST. 안에서 기다릴 일이 생기므로 async를 붙입니다.

STEP 3

보낸 데이터 꺼내기

// src/app/api/posts/route.ts

export async function POST(request: Request) {
  const data = await request.json();
}

request는 화면이 보낸 택배 상자. request.json()으로 열어서 데이터를 꺼냅니다 — 다 열릴 때까지 await.

STEP 4

추가하고 답장하기

push 한 줄 = 실제 서비스에선 DB에 저장하는 코드가 올 자리

// src/app/api/posts/route.ts

export async function POST(request: Request) {
  const data = await request.json();
  posts.push({ id: posts.length + 1, title: data.title, contents: data.contents });
  return Response.json(posts);
}

push로 배열 끝에 새 게시물을 추가하고, 달라진 posts를 그대로 답장합니다.

완성 코드 — GET + POST

// src/app/api/posts/route.ts

const posts = [
  { id: 1, title: "첫 글", contents: "안녕하세요!" },
  { id: 2, title: "둘째 글", contents: "반갑습니다!" },
];

export function GET() {
  return Response.json(posts);
}

export async function POST(request: Request) {
  const data = await request.json();
  posts.push({ id: posts.length + 1, title: data.title, contents: data.contents });
  return Response.json(posts);
}

화면에서 부르기 — fetch

// src/app/page.tsx

"use client";

export default function Home() {
  const handleClick = async () => {
    const res = await fetch("/api/posts", {
      method: "POST",
      body: JSON.stringify({ title: "셋째 글", contents: "잘 부탁해요!" }),
    });
    const posts = await res.json();
    console.log(posts);
  };

  return <button onClick={handleClick}>글 추가하기</button>;
}

주소 · method · body 세 가지면 끝 — 읽기만 할 땐 fetch("/api/posts") 한 줄
